字体资源的后缀（即文件格式）主要按通用兼容、专业设计、系统特定三大场景分类，不同格式的核心差异在于兼容性、功能扩展和用途，以下是常见格式的汇总：

| 后缀名 | 格式全称 | 特点/用途 | 兼容性 |
| ------ | -------- | ---------- | -------- |
| .ttf   | TrueType Font | 最通用格式，采用矢量轮廓技术，支持缩放无锯齿，体积较小 | 全平台兼容（Windows、Mac、Linux、手机、浏览器） |
| .otf   | OpenType Font | 基于TTF升级，支持更多字符（如特殊符号、多语言）、字形变体，适合专业设计 | 全平台兼容，功能比TTF更丰富 |
| .woff  | Web Open Font Format | 网页专用格式，对TTF/OTF压缩优化，加载速度快，支持元数据 | 主流浏览器（Chrome、Firefox、Edge）均支持 |
| .woff2 | Web Open Font Format 2.0 | WOFF的升级版，压缩率更高（比WOFF小30%左右），性能更优 | 现代浏览器（需版本较新，如Chrome 36+、Firefox 39+） |
| .ttc   | TrueType Collection | 字体集合文件，将多个相关TTF字体打包（如同一字体的常规、加粗、斜体版），减少文件冗余 | 全平台兼容，适合需要整套字体的场景 |
| .eot   | Embedded OpenType | 微软为旧版IE浏览器设计的网页字体格式，现在已逐步被WOFF2替代 | 仅支持IE 4-11，其他浏览器不兼容 |
| .dfont | Datafork TrueType Font | 苹果Mac OS X早期专用格式，将字体数据嵌入文件数据分支，不支持跨平台 | 仅兼容Mac系统，Windows无法直接识别 |
| .svg   | SVG Font | 基于矢量图形的字体格式，支持颜色、渐变、图形化字形，适合网页和移动端轻量场景 | 部分浏览器（如Chrome）支持，兼容性较弱，现在较少用 |
| .fon   | Font Resource File | Windows早期的字体格式，多为位图字体（缩放易模糊），功能简单 | 仅兼容Windows系统，现在几乎被TTF/OTF取代 |
